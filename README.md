# АРМ-АА — АРМ администратора автосалона

Учебный проект по дисциплине «Технология программирования».
Фрагменты модулей программного комплекса «АРМ администратора автосалона».

## Модули

- `arm_core.py` — М1 «Авторизация» и М2 «Учёт парка автомобилей».
- `clients.py` — М3 «Клиентская база»: проверка ИНН и телефона, карточка клиента.

## Требования

- Python 3.10 и выше;
- зависимости из `requirements.txt` (pytest).

## Запуск тестов

    pip install -r requirements.txt
    python -m pytest -v
